# Knellwood playtest

A turn-based fantasy tactics roguelite. This is an early playtest build; expect rough edges.

## Play it

1. **[Download Knellwood for Windows](https://github.com/bradhave94/knellwood-playtest/releases/latest/download/Knellwood-playtest.zip)** (about 600 MB).
2. Right-click the zip, choose **Extract All**, then open the extracted folder.
3. Double-click **Knellwood.exe**.

If Windows says "Windows protected your PC", click **More info**, then **Run anyway**. The build isn't code-signed yet.

You need Windows 10 or 11 (64-bit), a mouse and a keyboard. Nothing else to install.

## Updating

Download the new zip and extract it over the old folder, or delete the old folder first. Your saves live outside the game folder (`%USERPROFILE%\AppData\LocalLow\Knellwood\Knellwood\saves`), so they carry over.
